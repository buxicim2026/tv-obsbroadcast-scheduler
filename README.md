# tv-obsbroadcast-scheduler · 电视台式自动播出插件

> **一句话**：它就是一个**会自己按节目单连续播视频的"高级媒体源"**。
> 你在 OBS 里只放一个普通的**媒体源**（Media Source），剩下的交给它：把一堆视频/图片排成节目单，
> 像电视台一样到点自动硬切、播完自动接下一条，中间还能插播广告。

后台是一个本地 Rust 引擎 + **admin 网页节目单编辑器**：你只在网页里选文件、排顺序，
到点 OBS 就自动播，不需要手动拖时间轴，也不用碰 OBS 的播放按钮。

## 它能做什么

| 能力 | 说明 |
| --- | --- |
| **顺序连续播出** | 一个媒体源按节目单从上到下播放，前一条播完立刻切下一条（硬切，无转场） |
| **自动识别时长** | 导入视频时用浏览器本地解码读出真实时长，不用手填 |
| **6 种节目类型** | 正片 / 公益广告 / 频道ID / 节目预告 / 宣传片 / 插播内容 |
| **本机时间节目单** | 设定开播时间后自动排出每条的播出时间；启用自动播出只负责按这张时间表开播，随时可提前排期 |
| **播出状态** | 每条节目显示 等待中 / 播出中 / 已完成 / 异常（文件丢失会标红） |
| **拖拽排序 + 批量删除** | 鼠标直接拖动行首的 ⠿ 调整播出顺序（↑↓ 也保留），勾选后批量删除 |
| **人工干预自动顺排** | 暂停会把后面节目整体顺延、跳档会把后面节目紧凑重排，拖拽后 likewise 自动衔接 —— 不会留下黑屏空档 |
| **电视台报时器** | 整点 / 半点在画面上浮出一分钟报时（精确到秒），字体、字号、背景透明度、显示位置可调，随时开关 |
| **国家授时中心授时** | 通过 NTP 与授时中心对时，报时器按授时时间显示（本机时间不准也不影响）；播出调度仍用本机时间，可一键立即授时 |
| **崩溃恢复** | 状态落盘，OBS 或引擎重启后从当前时间点接着排 |
| **三平台** | Windows 10+ / Linux（x64、arm64）/ macOS 13+ Apple Silicon |
| **凭据本地保存** | OBS 密码、节目单都只存在本机的 `config.json` |

## 安装（3 步）

> 前端是 **OBS Lua 脚本**（不是二进制 DLL），由 OBS 自己加载执行，
> 因此不存在"DLL 导出符号 / libobs ABI 不匹配 / 缺 VC++ 运行库"这类加载失败问题。

**1. 下载**
从 [Releases](../../releases) 取对应平台的文件：

- `tv-obsbroadcast-scheduler-windows-x64.zip`
- `tv-obsbroadcast-scheduler-linux-x64.tar.gz`
- `tv-obsbroadcast-scheduler-macos-arm64.tar.gz`

**2. 解压，保持这个结构**（`engine` 必须和 lua 在同一层）：

```
tv-obsbroadcast-scheduler\
├── tv_obsbroadcast_scheduler.lua        ← 在 OBS 里加载这个文件
└── engine\
    └── tv-obsbroadcast-scheduler.exe    ← Rust 引擎，由脚本自动拉起（不会弹黑窗）
```

**3. 加载脚本**
OBS 菜单 **工具 → 脚本 → 右下角「＋」→ 选择 `tv_obsbroadcast_scheduler.lua`**。

加载后脚本会自动拉起引擎（无窗口、后台运行）。OBS 日志里出现 `[TVBS] settings pushed` 即表示引擎已接上凭据。

## 5 分钟上手

### 第 1 步：在场景里放一个「媒体源」

场景内 **＋ → 添加来源 → 媒体源（Media Source）**，名字随意（例如 `main_media`），**不要勾"本地文件"以外的远程串流**。

> ⚠️ 请务必用 **媒体源（ffmpeg_source）**，不要用 VLC 视频源 —— 引擎通过 obs-websocket 的媒体控制接口驱动它。

### 第 2 步：开启 OBS WebSocket

**工具 → WebSocket 服务器设置 → 启用 WebSocket 服务器**，记下端口（默认 `4455`）和密码。

### 第 3 步：在脚本面板填凭据

加载脚本后，在脚本面板里填：

| 项 | 值 |
| --- | --- |
| OBS WebSocket Host | `127.0.0.1` |
| OBS WebSocket Port | `4455` |
| Password | 第 2 步的密码 |
| **Media Source Name** | 第 1 步那个媒体源的名字（如 `main_media`） |

点 **Test Connection**：
- 成功 → OBS 日志出现 `Test Connection OK`
- 失败 → 日志会写清 HTTP 状态码（见[排错](#常见问题--排错)）

也可以在 admin 的「设置」页里填，**目标媒体源请从下拉里选**（列表直接来自 OBS）。

### 第 4 步：编排节目单

点 **Open Admin in Browser**，或浏览器打开 <http://127.0.0.1:8789/admin>：

1. 进「节目清单」页
2. 点「**📁 选择文件（可多选，直接导入）**」，一次选中今天要播的所有视频 → **选完即导入**
   （文件会传到引擎自己的 `media` 目录，名称和时长自动填好，不用填任何路径）
3. 不想上传（文件已在本机、体积很大）时，用「🗂 从本机已有文件选择」直接引用
4. 表格里给每条选「节目类型」（默认正片），用 ↑↓ 排顺序
5. 需要定点开播：设定「开播时间（本机时间）」→ 点「⏱ 按开播时间重排」

### 第 5 步：开始自动播出

回「主控台」点 **启用自动播出**：

- 它只是**启用**：节目按节目表里已经设定好的时间播，**不会**从你点击的那一刻重排
- 没到点的节目会等着，到点自动开播并逐条切下去
- 若当前已在某一档的时间窗口内，会立刻接管播放这一档
- 若所有节目时间都已过去，界面会提示你去重排（不会默默什么都不做）

**想整体顺延/提前**：到「节目表」页填「开播时间（本机时间）」→ 点「⏱ 按开播时间重排」。
这样就能提前把整张节目单的播出时间排好，再回主控台启用。

## admin 界面详解

地址：<http://127.0.0.1:8789/admin>

### 主控台

- **ON AIR**：播出中红灯会呼吸闪动，待机时熄灭
- 显示当前节目名、状态、**剩余时间（毫秒级）**、下一档预告
- 按钮：
  - **启用 / 停用自动播出**：按节目表已设定的时间启用播出（不会从点击时刻重排；要重排去节目表页点「⏱ 按开播时间重排」）
  - **暂停 / 继续**：暂停 OBS 画面并冻结倒计时；继续时从暂停处接着播，不会漏播内容
  - **下一档**：立即切到下一条节目，丢弃当前节目剩余部分
  - **重新载入**：让引擎重读磁盘上的 `config.json`，并按当前时间重新对齐时间轴
  - **清空**：清空活动日志
- **活动日志**：所有操作与错误都在这里，错误信息标红

### 节目清单

**导入区**

- **📁 选择文件（可多选，直接导入）**（推荐）：选中即导入。文件会上传到引擎的 `media` 目录，
  路径由引擎返回，**不会出现"异常"**；时长自动读取、名称取文件名。支持视频/图片/音频，单个上限 4GB。
- **🗂 从本机已有文件选择**：不上传，直接浏览引擎所在电脑的磁盘并引用已有文件（适合很大的文件）
- **📁 选择文件（可多选）**：选视频或图片；导入后
  - **名称** = 文件名（不用手填）
  - **时长** = 自动读取的真实时长（图片按 10 秒占位）
  - **类型** 默认正片，表格里可改
- **开播时间（本机时间）** + **⏱ 按开播时间重排**：按你设定的时刻排出整张节目单

**表格列**

| 列 | 说明 |
| --- | --- |
| 名称 | 文件名（鼠标悬停显示完整路径） |
| 节目类型 | 下拉可选：正片 / 公益广告 / 频道ID / 节目预告 / 宣传片 / 插播内容 |
| 时长 | 视频实际时长 |
| 播出时间 | 按**本机时间**显示该条的播出时刻 |
| 播出状态 | 等待中 / 播出中 / 已完成 / **异常**（文件丢失或路径无效会标红） |

**操作**

- ↑ ↓：调整播出顺序（交换两条的播出时间）
- 删除：单条删除（有二次确认）
- 勾选框 + **全选** + **🗑 删除选中**：批量删除
- **➕ 新增节目**：在表格下方，同样是选文件添加

**快捷键**：`Ctrl/⌘ + N` 跳到新增节目，`Ctrl/⌘ + S` 保存设置。

### 播出预设（保存 / 迁移整套节目表）

节目表页底部有一排「播出预设」按钮：

| 操作 | 说明 |
| --- | --- |
| 填写名称 → **保存当前节目表** | 把当前整套节目表存成预设（同名会覆盖）；勾选"连设置一起"还会存 Lead-in、报时器等设置 |
| 下拉选择 → **载入（替换当前节目表）** | **清空并替换**当前节目表为预设内容（会先弹窗确认） |
| 下拉选择 → **导出文件** | 下载一个 `.tvbs-preset.json`，用于备份或换机器 |
| **导入文件** | 读入别人给的 / 备份的预设文件，之后在下拉里选它再「载入」 |
| 下拉选择 → **删除** | 只删预设文件，不影响当前节目表 |

预设文件存放在引擎配置目录的 `presets/` 子目录（和 `config.json` 同级），是纯 JSON、可读可改。

> 换电脑 / 重装系统：把导出的 JSON 带过去 → 「导入文件」→「载入」，节目表就回来了。
> 注意**文件路径不会跟着变**，新机器上视频若换了盘符或目录，需要重新添加那些行。

### 设置

| 项 | 说明 |
| --- | --- |
| OBS WebSocket 主机 / 端口 / 密码 / TLS | 连接 OBS 的凭据 |
| **受控媒体源名称** | **从下拉里选**（直接读 OBS 真实来源，避免手打错字导致不播放）。在网页里选好后以网页为准；只有在 OBS 脚本属性里点「Test Connection」时才会改用脚本里的值 |
| Lead-in（毫秒） | 提前多少毫秒把下一个文件准备好，默认 200ms |
| 时钟偏移（毫秒） | 与外部主时钟对齐用，默认 0 |
| 缺文件策略 | 自动跳到下一条（默认）/ 保持最后一帧并报错 / 暂停调度器 |

按钮：**保存**（写入引擎并落盘）、**测试连接**（显示引擎版本 + OBS 是否已连接及原因）。

## 播出浮窗（overlay）

地址：<http://127.0.0.1:8789/overlay>

在 OBS 里加一个**浏览器源**指向它（建议 1920×120，放在画面底部），
会显示：ON AIR 灯、当前节目名、下一档、剩余时间。admin 页脚也有「打开浮窗」链接。

### 报时器（clock）

地址：<http://127.0.0.1:8789/clock>

像电视台那样在**整点与半点**浮出一分钟报时。用法：

1. 在 OBS 场景里再加一个**浏览器源**，地址填上面的 `/clock`（建议 960×240，放在你想让报时出现的位置）
2. 到 admin 的**系统设置 → 电视台报时器**里打开开关，可调：

| 项目 | 说明 |
| --- | --- |
| 启用整点 / 半点报时 | 总开关，关掉时页面上什么都不显示 |
| 字体 | 可下拉选择：点「读取字体」向浏览器申请本机已安装字体列表；也支持手动填写 CSS `font-family` |
| 字号 | 数字的像素高度（12–400，默认 72） |
| 底板样式 | 胶囊 / 椭圆（默认，电视台常见）、圆角矩形、直角矩形、不要底板 |
| 背景透明度 | 底板透明度 0–100%，填 0 即完全透明（默认 45%） |
| 显示时长 | 每次浮出多少秒，默认 60 秒（即电视台常见的一分钟） |
| 提前多少秒开始显示 | 默认 30 秒 —— 于是报时窗口是 **11:59:30 → 12:00:30**（跨整点，而不是整点之后才开始） |
| 显示位置 | 左上 / 右上 / 上中 / 左下 / 右下 / 下中 |

- 数字是**七段数码管**样式（用 CSS 画出来，不依赖任何字体文件，换机器长得一样）
- 页面背景**透明**，不挡下面的画面；只在报时窗口内出现，其余时间自动隐去
- 时间由本机时钟按帧计算，**精确到秒**，不会因网络推送延迟而与视频错位
- 显示位置由"显示位置"决定，浏览器源本身可以拉满画布

### 授时（国家授时中心 NTP）

报时器显示的时间**不是本机时间**。引擎会向授时服务器对时，把"本机时钟快/慢了多少"
记成一个偏移量，报时器按 `本机时间 + 偏移量` 显示。

> 播出调度**不使用**这个偏移，仍按本机系统时间（外加可手动设置的「时钟偏移」）。
> 这样设计是刻意的：万一某台授时服务器返回了离谱的时间，最坏情况只是报时显示不对，
> 绝不会导致节目单找不到节目、播出起不来。

- 默认服务器 `ntp.ntsc.ac.cn`（中国科学院国家授时中心），连不上时依次回退 `cn.ntp.org.cn`、`pool.ntp.org`
- 引擎启动即自动授时一次，之后每 30 分钟一次（可在设置页改）
- 设置页可开关、改服务器、改间隔，并有「立即授时」按钮，旁边显示"已同步到哪台服务器、偏差多少毫秒、什么时候同步的"
- 关掉授时就退回纯本机时间

之所以用"偏移量"而不是直接取服务器时间：即便本机时钟错了一小时，NTP 的四个时间戳
相减仍能得到正确的偏差，所以**系统时间不准也不会影响播出和报时**。

## 工作原理

```
OBS Studio
  ├── Lua 脚本（tv_obsbroadcast_scheduler.lua）  ← OBS 加载，提供属性面板，拉起引擎
  │        └── 启动 engine/tv-obsbroadcast-scheduler（无窗口）
  │
  └── 媒体源（main_media）  ← 实际播放画面
           ▲
           │ obs-websocket v5（SetInputSettings 换文件 + TriggerMediaInputAction 播放）
           │
      Rust 引擎（本地 HTTP 8789 + 调度器）
           ▲
           │ 浏览器
      admin 网页（节目单编辑）
```

- **Lua 脚本**：注册控制用 source、提供属性面板、启动并监控引擎、把凭据（含授权令牌）推给引擎
- **Rust 引擎**：调度推进、节目表存储、obs-websocket 通信、本地 HTTP/WebSocket 服务（admin 与浮窗）
- 引擎只在**切档时**改媒体源的文件并触发播放，OBS 媒体源自身的播放/暂停/停止按钮照常可用

## 常见问题 / 排错

| 现象 | 原因与处理 |
| --- | --- |
| **完全不播放** | ① 目标源填错 → 设置页从**下拉**里选真实来源；② 用的不是媒体源（VLC 源不支持）→ 换成媒体源；③ 文件路径不对 → 该条会显示"异常"，改用「🗂 浏览本机文件」重新添加。切档 1.5 秒后主控台会给出 OBS 的确认结果 |
| 节目条显示**异常** | 文件被移动/删除，或者浏览器选文件时"媒体所在目录"没填对。用「🗂 浏览本机文件」添加可避免 |
| **OBS 一启动就自己开播** | 不应该发生：引擎每次启动都会先解除自动播出，保持待命，等你在面板里点「启用自动播出」 |
| 播的还是上一个文件 | 一般已修复；若仍出现，看主控台活动日志里的 `cut:` 报错 |
| 引擎起不来 | 手动双击 `engine/tv-obsbroadcast-scheduler.exe` 试试（应无窗口、后台运行）；检查是否被杀软拦截 |
| OBS 一直"未连接" | 工具 → WebSocket 服务器设置 是否启用；端口/密码是否与脚本面板一致；引擎是否在运行 |
| 新增节目提示"没有通过授权" | 在 OBS 脚本面板点一次 **Test Connection**（引擎会把授权令牌交给脚本）；引擎现在也会在 WS 推送里带上令牌，理论上不会再丢 |
| admin 打开是空白/样式丢了 | 强制刷新一次（Ctrl+F5）；端口应为 8789 |
| 时间到了没切 | 检查是否点了「启用自动播出」；节目单的播出时间是否还在未来 |
| 想换播出顺序 | 用 ↑↓，或勾选后删除重新导入；顺序即播放顺序 |

日志位置：OBS 菜单 **帮助 → 日志文件 → 查看当前日志**，筛选 `[TVBS]`。

## 目录结构与本地编译

```
tv-obsbroadcast-scheduler/
├── obs-script/tv_obsbroadcast_scheduler.lua   # OBS 前端脚本
├── engine/                                    # Rust 引擎
│   └── src/  (scheduler / playlist / obs_ws / server / media_probe …)
├── admin/                                     # admin 网页（编译进引擎，单文件分发）
├── overlay/                                   # 播出浮窗（同样内嵌）
├── scripts/                                   # 打包脚本
├── docs/                                      # 架构与开发文档
└── plugin-c-legacy/                           # 早期 C 插件，已归档，不参与构建
```

本地编译（只需 Rust 1.74+，前端是 Lua 脚本，不需要 OBS SDK）：

```bash
cargo build --release --manifest-path engine/Cargo.toml
# 产物在 target/release/tv-obsbroadcast-scheduler(.exe)
# 放到 lua 同级的 engine/ 目录即可使用
```
