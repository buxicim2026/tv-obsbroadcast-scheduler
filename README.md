# tv-obsbroadcast-scheduler · 电视台式自动播出插件

> **一句话**：它就是一个**会自己按节目单连续播视频的"高级媒体源"**。
> 你在 OBS 里只放一个普通的**媒体源**（Media Source），剩下的交给它：把一堆视频/图片排成节目单，
> 像电视台一样到点自动硬切、播完自动接下一条，中间还能插播广告。

后台是一个本地 Rust 引擎 + **admin 网页节目单编辑器**：你只在网页里选文件、排顺序，
到点 OBS 就自动播，不需要手动拖时间轴，也不用碰 OBS 的播放按钮。

## 它能做什么

| 能力 | 说明 |
| --- | --- |
| **顺序连续播出** | 一个媒体源按节目单从上到下播放，前一条播完立刻切下一条（硬切，无转场） |
| **自动识别时长** | 导入视频时用浏览器本地解码读出真实时长，不用手填 |
| **6 种节目类型** | 正片 / 公益广告 / 频道ID / 节目预告 / 宣传片 / 插播内容 |
| **北京时间节目单** | 设定开播时间后自动排出每条的播出时间；也可"以点开始播出的那一刻"为基准整体顺延或提前 |
| **播出状态** | 每条节目显示 等待中 / 播出中 / 已完成 / 异常（文件丢失会标红） |
| **自由排序 + 批量删除** | ↑↓ 调整顺序，勾选后批量删除 |
| **播出浮窗** | 可选的下沿字幕条：正在播什么、下一档、剩余时间 |
| **崩溃恢复** | 状态落盘，OBS 或引擎重启后从当前时间点接着排 |
| **三平台** | Windows 10+ / Linux（x64、arm64）/ macOS 13+ Apple Silicon |
| **凭据本地保存** | OBS 密码、节目单都只存在本机的 `config.json` |

## 安装（3 步）

> 前端是 **OBS Lua 脚本**（不是二进制 DLL），由 OBS 自己加载执行，
> 因此不存在"DLL 导出符号 / libobs ABI 不匹配 / 缺 VC++ 运行库"这类加载失败问题。

**1. 下载**
从 [Releases](../../releases) 取对应平台的文件：

- `tv-obsbroadcast-scheduler-windows-x64.zip`
- `tv-obsbroadcast-scheduler-linux-x64.tar.gz`
- `tv-obsbroadcast-scheduler-macos-arm64.tar.gz`

**2. 解压，保持这个结构**（`engine` 必须和 lua 在同一层）：

```
tv-obsbroadcast-scheduler\
├── tv_obsbroadcast_scheduler.lua        ← 在 OBS 里加载这个文件
└── engine\
    └── tv-obsbroadcast-scheduler.exe    ← Rust 引擎，由脚本自动拉起（不会弹黑窗）
```

**3. 加载脚本**
OBS 菜单 **工具 → 脚本 → 右下角「＋」→ 选择 `tv_obsbroadcast_scheduler.lua`**。

加载后脚本会自动拉起引擎（无窗口、后台运行）。OBS 日志里出现 `[TVBS] settings pushed` 即表示引擎已接上凭据。

## 5 分钟上手

### 第 1 步：在场景里放一个「媒体源」

场景内 **＋ → 添加来源 → 媒体源（Media Source）**，名字随意（例如 `main_media`），**不要勾"本地文件"以外的远程串流**。

> ⚠️ 请务必用 **媒体源（ffmpeg_source）**，不要用 VLC 视频源 —— 引擎通过 obs-websocket 的媒体控制接口驱动它。

### 第 2 步：开启 OBS WebSocket

**工具 → WebSocket 服务器设置 → 启用 WebSocket 服务器**，记下端口（默认 `4455`）和密码。

### 第 3 步：在脚本面板填凭据

加载脚本后，在脚本面板里填：

| 项 | 值 |
| --- | --- |
| OBS WebSocket Host | `127.0.0.1` |
| OBS WebSocket Port | `4455` |
| Password | 第 2 步的密码 |
| **Media Source Name** | 第 1 步那个媒体源的名字（如 `main_media`） |

点 **Test Connection**：
- 成功 → OBS 日志出现 `Test Connection OK`
- 失败 → 日志会写清 HTTP 状态码（见[排错](#常见问题--排错)）

也可以在 admin 的「设置」页里填，**目标媒体源请从下拉里选**（列表直接来自 OBS）。

### 第 4 步：编排节目单

点 **Open Admin in Browser**，或浏览器打开 <http://127.0.0.1:8789/admin>：

1. 进「节目清单」页
2. 先填一次「**媒体所在目录**」（例如 `D:\media`）
   —— 浏览器出于安全不会给出文件的完整路径，所以引擎需要这个目录来拼出 `D:\media\片头.mp4`
3. 点「**📁 选择文件（可多选）**」，一次选完今天要播的所有视频
4. 表格里给每条选「节目类型」（默认正片），用 ↑↓ 排顺序
5. 需要定点开播：设定「开播时间（北京时间）」→ 点「⏱ 按开播时间重排」

### 第 5 步：开始自动播出

回「主控台」点 **启用自动播出**：

- 节目单会**以你按下按钮的这一刻为基准**重排第一条
- 比预定时间晚 → 整体**顺延**；早 → 整体**提前**
- 之后引擎到点自动切文件并触发播放，OBS 里就会连续播下去

想定点播出时，就用第 4 步的「开播时间」重排（不要按自动播出），到点会自动开始。

## admin 界面详解

地址：<http://127.0.0.1:8789/admin>

### 主控台

- **ON AIR**：播出中红灯会呼吸闪动，待机时熄灭
- 显示当前节目名、状态、**剩余时间（毫秒级）**、下一档预告
- 按钮：
  - **启用 / 停用自动播出**：开始即以当前时刻为基准重排节目单
  - **重新载入**：手动拉取最新数据
  - **清空**：清空活动日志
- **活动日志**：所有操作与错误都在这里，错误信息标红

### 节目清单

**导入区**

- **媒体所在目录**：填一次即可，会记住（用于拼接文件绝对路径）
- **📁 选择文件（可多选）**：选视频或图片；导入后
  - **名称** = 文件名（不用手填）
  - **时长** = 自动读取的真实时长（图片按 10 秒占位）
  - **类型** 默认正片，表格里可改
- **开播时间（北京时间）** + **⏱ 按开播时间重排**：按你设定的时刻排出整张节目单

**表格列**

| 列 | 说明 |
| --- | --- |
| 名称 | 文件名（鼠标悬停显示完整路径） |
| 节目类型 | 下拉可选：正片 / 公益广告 / 频道ID / 节目预告 / 宣传片 / 插播内容 |
| 时长 | 视频实际时长 |
| 播出时间 | 按**北京时间**显示该条的播出时刻 |
| 播出状态 | 等待中 / 播出中 / 已完成 / **异常**（文件丢失或路径无效会标红） |

**操作**

- ↑ ↓：调整播出顺序（交换两条的播出时间）
- 删除：单条删除（有二次确认）
- 勾选框 + **全选** + **🗑 删除选中**：批量删除
- **➕ 新增节目**：在表格下方，同样是选文件添加

**快捷键**：`Ctrl/⌘ + N` 跳到新增节目，`Ctrl/⌘ + S` 保存设置。

### 时间轴

24 小时可视化：色块是节目，红线是当前时刻；插播内容会按其触发点画在对应节目上。
可用 ← 前一天 / 跳到今天 / 后一天 → 翻看。

### 设置

| 项 | 说明 |
| --- | --- |
| OBS WebSocket 主机 / 端口 / 密码 / TLS | 连接 OBS 的凭据 |
| **受控媒体源名称** | **从下拉里选**（直接读 OBS 真实来源，避免手打错字导致不播放） |
| Lead-in（毫秒） | 提前多少毫秒把下一个文件准备好，默认 200ms |
| 时钟偏移（毫秒） | 与外部主时钟对齐用，默认 0 |
| 缺文件策略 | 自动跳到下一条（默认）/ 保持最后一帧并报错 / 暂停调度器 |

按钮：**保存**（写入引擎并落盘）、**测试连接**（显示引擎版本 + OBS 是否已连接及原因）。

## 播出浮窗（overlay）

地址：<http://127.0.0.1:8789/overlay>

在 OBS 里加一个**浏览器源**指向它（建议 1920×120，放在画面底部），
会显示：ON AIR 灯、当前节目名、下一档、剩余时间。admin 页脚也有「打开浮窗」链接。

## 工作原理

```
OBS Studio
  ├── Lua 脚本（tv_obsbroadcast_scheduler.lua）  ← OBS 加载，提供属性面板，拉起引擎
  │        └── 启动 engine/tv-obsbroadcast-scheduler（无窗口）
  │
  └── 媒体源（main_media）  ← 实际播放画面
           ▲
           │ obs-websocket v5（SetInputSettings 换文件 + TriggerMediaInputAction 播放）
           │
      Rust 引擎（本地 HTTP 8789 + 调度器）
           ▲
           │ 浏览器
      admin 网页（节目单编辑）
```

- **Lua 脚本**：注册控制用 source、提供属性面板、启动并监控引擎、把凭据（含授权令牌）推给引擎
- **Rust 引擎**：调度推进、节目表存储、obs-websocket 通信、本地 HTTP/WebSocket 服务（admin 与浮窗）
- 引擎只在**切档时**改媒体源的文件并触发播放，OBS 媒体源自身的播放/暂停/停止按钮照常可用

## 常见问题 / 排错

| 现象 | 原因与处理 |
| --- | --- |
| **完全不播放** | ① 目标源填错 → 设置页从**下拉**里选真实来源；② 用的不是媒体源（VLC 源不支持）→ 换成媒体源；③ 文件路径不对 → 节目清单里该条会显示"异常"，补填「媒体所在目录」后重新导入 |
| 节目条显示**异常** | 文件被移动/删除，或"媒体所在目录"没填对，引擎找不到该文件 |
| 播的还是上一个文件 | 一般已修复；若仍出现，看主控台活动日志里的 `cut:` 报错 |
| 引擎起不来 | 手动双击 `engine/tv-obsbroadcast-scheduler.exe` 试试（应无窗口、后台运行）；检查是否被杀软拦截 |
| OBS 一直"未连接" | 工具 → WebSocket 服务器设置 是否启用；端口/密码是否与脚本面板一致；引擎是否在运行 |
| 新增节目提示"没有通过授权" | 在 OBS 脚本面板点一次 **Test Connection**（引擎会把授权令牌交给脚本）；引擎现在也会在 WS 推送里带上令牌，理论上不会再丢 |
| admin 打开是空白/样式丢了 | 强制刷新一次（Ctrl+F5）；端口应为 8789 |
| 时间到了没切 | 检查是否点了「启用自动播出」；节目单的播出时间是否还在未来 |
| 想换播出顺序 | 用 ↑↓，或勾选后删除重新导入；顺序即播放顺序 |

日志位置：OBS 菜单 **帮助 → 日志文件 → 查看当前日志**，筛选 `[TVBS]`。

## 目录结构与本地编译

```
tv-obsbroadcast-scheduler/
├── obs-script/tv_obsbroadcast_scheduler.lua   # OBS 前端脚本
├── engine/                                    # Rust 引擎
│   └── src/  (scheduler / playlist / obs_ws / server / media_probe …)
├── admin/                                     # admin 网页（编译进引擎，单文件分发）
├── overlay/                                   # 播出浮窗（同样内嵌）
├── scripts/                                   # 打包脚本
├── docs/                                      # 架构与开发文档
└── plugin-c-legacy/                           # 早期 C 插件，已归档，不参与构建
```

本地编译（只需 Rust 1.74+，前端是 Lua 脚本，不需要 OBS SDK）：

```bash
cargo build --release --manifest-path engine/Cargo.toml
# 产物在 target/release/tv-obsbroadcast-scheduler(.exe)
# 放到 lua 同级的 engine/ 目录即可使用
```
