    节目清单

    选中即导入：自动读取时长、以文件名命名，文件保存在引擎的 media 目录，无需填任何路径。
    填好开播时间后点这个按钮，整张节目单就从那一刻起顺序排出；之后点「启用自动播出」只是启用， 节目按你设定的时间播出，不会从点击那一刻重排。
    直接用鼠标拖动行首的 ⠿ 即可调整播出顺序（已播出的节目不可拖动）。
    名称（悬停看全名） 节目类型 时长 播出时间 播出状态 操作

    电视台报时器（整点 / 半点）

    点「读取字体」会向浏览器申请本机字体列表；读不到时下面手动填写也可以。
    默认提前 30 秒、显示 60 秒，即 11:59:30 → 12:00:30。

    用法：在 OBS 场景里新增一个「浏览器源」，地址填 http://127.0.0.1:8789/clock（建议宽高 960×240）。页面背景透明， 数字为七段数码管样式，在整点与半点前后浮出（默认 11:59:30 → 12:00:30）， 显示到秒，时间一到自动隐去，不影响下面的画面。

    授时（国家授时中心 NTP）

    默认 ntp.ntsc.ac.cn（中国科学院国家授时中心）； 连不上时依次回退 cn.ntp.org.cn、pool.ntp.org。
    引擎启动时也会自动授时一次。

    报时器按授时中心的时间显示，所以本机时钟不准也不会报错时间。 播出调度仍使用本机系统时间（另有「时钟偏移」可手动对齐外部主时钟）—— 这样即使授时异常，也只会影响报时显示，不可能让节目播不出来。
